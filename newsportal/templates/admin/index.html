Where your content appears

  • Checked (published) updates appear in the homepage latest-updates feed and the public View All Updates page. Drafts stay hidden.
  • The selected category labels the update and filters it in the public updates list. Homepage category links open those filtered results.
  • Short descriptions appear on update cards. The detail page shows the full description, or the short description if the full description is blank.
  • Detail pages show supported category-specific fields and an official-link button when a URL is provided.
  • The lower homepage Jobs, Scholarship, Results and other promotional blocks are static and are not populated from these records. Images and attachments are not supported by this model.
